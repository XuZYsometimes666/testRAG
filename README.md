# testRAG

我的第一个 GitHub 仓库，用来练习 Git 基本操作，以及记录 RAG 相关的实验。

## 已经跑通的流程

```
git clone git@github.com:XuZYsometimes666/testRAG.git
# 修改文件
git add .
git commit -m "说明这次改了什么"
git push
```

## 命令速查

| 命令 | 作用 |
|---|---|
| `git status` | 看当前改了哪些文件 |
| `git add .` | 把改动放进暂存区 |
| `git commit -m "说明"` | 存档一次 |
| `git push` | 推到 GitHub |
| `git pull` | 拉取别人的改动 |
| `git log --oneline` | 看提交历史 |
